One wall
Any internal user sees cost. No external view renders it, ever — including margin %, discount depth, floor-price warnings and toll rate cards.
Not rendered
Restricted nav and fields don't exist for the role. Nothing appears greyed out, and the interface is never the enforcement mechanism.
Gates first
License, release and AR gates decide availability before any screen does. Each blocked state names a reason and a path forward.

Cost visibility

You named cost visibility as the leak that worries you most, so it gets the sharpest rule in the document. The wall runs between internal and external, not between internal domains — which trades internal least-privilege for a rule people can actually hold in their heads.
